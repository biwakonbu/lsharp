# まえがき {.unnumbered}

本書は、プログラミング言語 L# のコンパイラを実装する過程を通じて、言語処理系の設計と実装を解説する技術書である。

## なぜコンパイラを書くのか {.unnumbered}

コンパイラは計算機科学の中でも最も体系化された分野の一つである。字句解析、構文解析、型推論、中間表現、コード生成——これらの各段階は独立した理論に支えられながらも、一つのパイプラインとして有機的に結びついている。

コンパイラを自分の手で実装することは、プログラミングの本質を深く理解する最良の方法の一つである。文字列として入力されたソースコードが、どのようにして実行可能なバイナリに変換されるのか。その過程を追うことで、普段何気なく使っているプログラミング言語の裏側にある仕組みが見えてくる。

## L# という言語について {.unnumbered}

L# (エルシャープ) は、Lisp の S 式構文と ML 系言語の Hindley-Milner 型推論を組み合わせた言語である。WebAssembly をコンパイルターゲットとすることで、ブラウザやサーバー、エッジ環境で同一のコードを実行できる。

S 式構文を採用した理由は、パーサーの実装が劇的に簡単になるからである。括弧で囲まれた構造は再帰的に処理するだけでよく、演算子の優先順位や結合性を考慮する必要がない。これにより、本書の焦点を構文解析の複雑さではなく、型推論やコード生成といったコンパイラの本質的な部分に置くことができる。

## 本書の対象読者 {.unnumbered}

本書は以下のような読者を想定している:

- プログラミング言語の仕組みに興味がある開発者
- Rust の基本的な文法を理解している方
- コンパイラ実装に挑戦したいが、どこから始めればよいかわからない方

型理論やコンパイラ理論の事前知識は不要である。必要な概念はその都度解説する。

L# でアプリケーションやライブラリを書くための手順は、リポジトリの `docs/guides/` を正面玄関とする。本書は L# コンパイラ実装を読むための読み物であり、字句解析、構文解析、型推論、IR、コード生成、selfhost、LSP などの内部構造を扱う。

公開 CLI の通常利用では `lsharp compile` / `lsharp test` / `lsharp doc` / `lsharp lsp` / `lsharp mcp-server` を入口にする。`parse` / `check` / `fmt` の詳細は、LSP / MCP / 内部 tooling を理解する文脈で扱う。

## 本書のコードについて {.unnumbered}

本書に掲載するコードは、全て実際に動作する L# コンパイラの実装から引用している。仮想的なコードや疑似コードは最小限にとどめ、読者が実際のソースコードと対照しながら読み進められるようにした。

L# コンパイラのソースコードは以下のリポジトリで公開されている:

```
https://github.com/biwakonbu/lsharp
```

## 謝辞 {.unnumbered}

本書の執筆にあたり、コンパイラ実装の先駆的な書籍である "Crafting Interpreters" (Robert Nystrom)、"Types and Programming Languages" (Benjamin C. Pierce)、"Real World OCaml" (Yaron Minsky 他) から多大な影響を受けた。

また、Rust コミュニティ、WebAssembly コミュニティの方々が公開している資料やツールなしには、L# コンパイラの実装は不可能であった。特に `wasm-encoder`、`wasmtime`、`miette`、`insta` の開発者に感謝する。
