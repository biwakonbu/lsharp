# ドキュメント同期 (doc-first)

TDD が「テストを先に書く」規律であるのと同じ意味で、このリポジトリは **「決定を先に書く」** 規律を持つ。
ドキュメント更新は作業の後片付けではなく、作業の一部である。ユーザーから依頼されて初めて更新する、
という運用にはしない。

## 必須フロー

1. **doc-RED**: 何を決めたか・何が問題かを正本へ書く。この時点で証拠はまだ無くてよい
2. **実装**: TDD (RED → GREEN → REFACTOR) で進める
3. **doc-GREEN**: 実測値・test 名・受入判定を正本へ戻す。満たせなかった受入条件は**必ず明示する**

順序が逆になると、決定の根拠がコミットメッセージにしか残らず、台帳に無い既知問題が生まれる
(実例: `ISSUES.md` の `I-10`)。

## 変更種別 → 更新すべき正本

| 変更種別 | 更新先 | 備考 |
|---|---|---|
| 問題を新たに認識した | `ISSUES.md` | `D-NN` / `I-NN` / `DOC-NN`。欠番は再利用しない。**チェックボックスは置かない** |
| これからやる作業を決めた | `TODO.md` | `[ ]` / `[~]` / `[BLOCKED: 理由]`。**`[x]` は使わない** |
| 設計上の判断をした・何かを却下した | `docs/adr/decisions-*.md` | 何を採り、何を却下し、**なぜか**。却下理由は採用理由と同じだけ価値がある |
| 挙動・契約が変わった | `docs/language/` | v1 契約仕様 |
| 計測した・運用手順が変わった | `docs/development/operations/` | 実測値とその取得条件 |
| 日常の作業手順が変わった | `AGENTS.md` | 新しいスクリプトを足したらここ |
| 作業が完了した | 該当 ADR / 運用記録へ移し `TODO.md` から**削除** | `TODO.md` は未完了だけの単一正本 |

配置の詳細は [docs-organization.md](docs-organization.md) が正本。ここでは「いつ書くか」だけを定める。

## 受入条件を満たせなかった場合

満たせなかった事実を書く。数字を静かに直したり、条件を後から緩めたりしない。
「文言どおりには満たしていないが、意図は満たしている」と判断したなら、**その判断と根拠を書く**。
実例は [`decisions-dev-loop-rust-lane-speedup.md`](../../docs/adr/decisions-dev-loop-rust-lane-speedup.md)
の「workspace 検証の結果と、満たせなかった受入条件」節。

## この規律を要求しない変更

判断を含まない機械的な変更にはドキュメント更新を要求しない。

- test の split / rename / 移動 (ただし ADR を伴う split は従来どおり ADR を書く)
- typo 修正、rustfmt、import 整理
- 既存挙動を変えないリファクタ

## 機械的な補助

`.claude/hooks/doc-guard.sh` が PreToolUse (Edit|Write) で発火し、実装ファイルを編集しようとした時点で
正本ドキュメントが未変更なら stderr に `[Doc Guard]` 警告を出す。
**この hook はブロックしない (`exit 0`)。** 上記「要求しない変更」を止めてしまうため、判断はエージェント側に残す。

hook が判定できるのは「何かを書いたか」だけである。**正しい正本に、正しい粒度で書かれたか**は
判定できないので、そこは [`doc-sync` skill](../skills/doc-sync/SKILL.md) のチェックリストと人のレビューに委ねる。

判定は working tree の dirty 状態で行うため、**commit が事実上のリセット境界**になる。
未コミットのまま複数の slice を跨ぐと、2 番目以降の slice では docs が既に dirty なので警告が出ない。
slice を閉じたら commit する運用を前提とする。

## スキルの追加について

作業の中で繰り返し必要になる手順が現れたら、その都度 `.claude/skills/<name>/SKILL.md` として
切り出す。一度きりの手順は切り出さない。切り出したら本ルールか `AGENTS.md` から参照を張り、
発見できる状態にする。
