# L# v0.3 Milestone 1 — source/native provenance closure

- Status: Active planning
- Date: 2026-07-31
- Parent design: [`v0.3-review-provenance-lifecycle.md`](v0.3-review-provenance-lifecycle.md)
- Scope: `EC-M3-04` / `EC-M3-05`

## 目的

Rust canonical model と Rust-host の selfhost Wasm で検証済みの review attestation / evidence
identity を、current-source の native stage0、packaged artifact、release evidence へ同じ observable
contract のまま接続する。既存の partial slice を完了扱いへ拡大解釈せず、source、selfhost、native、
release の境界ごとに実行可能な task と validation gate を固定する。

## 次の task

### M3-04-N1 — current-source native source-file parity

同一の `:review-attestation` fixtureを Rust oracle、selfhost producer、Mac Apple Silicon native stage0、
Linux x86_64 native stage0 へ渡し、次の値を機械比較する。

- named fields と field order
- length-prefixed UTF-8 canonical bytes（`expires-at` 有無を含む）
- producer state (`unverified`)
- directive span (`start` / `end`)
- valid / invalid の source error code と exit code
- report/manifest の有無、stdout/stderr の境界

成功経路は `cargo`、`rustc`、host `lsharp`、network、暗黙の trust store/lifecycle を呼ばない。
native stage0 の source commit と fixture producer fingerprint が current checkout に一致しない場合は
失敗として扱う。

2026-07-31 の verified partial slice は、Rust/selfhost の JSON report に named fields、field order、
期限付き/期限なしの `expires_at`、canonical bytes、`unverified`、directive span を追加し、Rust
focused test、selfhost `EmbeddedCli` actual Wasm E2E、Linux source-file static/provenance harness
で同じ fixtureを検証した。2026-07-31 に current `f6a6da30` の Mac Apple Silicon stage0 producer/package と
`native-selfhost-dev-source-file-smoke.sh` を実行し、actual App.Cli E2E（542.31秒）と source-file smoke が
passした。Linux x86_64 current-source runtime、packaged provenance と両 target matrixは未検証のため、
M3-04-N1 は `[~]` のまま残す。
なお、既定 macOS `TMPDIR` の task-owned artifact path が内側 producer の安全検査で拒否される RED も
再現し、`TMPDIR_ROOT/lsharp-*` だけを許可する fail-closed boundaryを追加した。その後、末尾 `/` を含む
既定 `TMPDIR` が `T//lsharp-*` を生成する外側 wrapperの連結不備を RED として固定し、
`TMPDIR_ROOT="${TMPDIR_ROOT%/}"` で正規化した。既定 `TMPDIR=/var/folders/.../T/` の actual
Mac producer/package（484.89秒）と生成 stage0の source-file smoke は GREEN である。

さらに current `3e1b26901aef8191a47382b06bf87fe62c9fb9ad` の Mac Apple Silicon producer/package を実行し、

### M3-05-N1 — native evidence identity projection

emitted manifest の両方に `review_evidence_identity` を暗黙追加しない回帰契約を追加した。
explicit identity route、nullable digest、partial input拒否と同じ fake Linux provenance harness で

### M3-05-N2 — release identity gate

keyset digest、lifecycle snapshot digest、source commit、artifact digest を evidence identity に束ね、
Mac/Linux の packaged stage0 と release smoke が同じ identity を出すことを検証する。provider adapter は
外部入力境界に留め、helper 不在や digest mismatch を `verified` として扱わない。

既存 release surface には [`verify-native-release-identity.py`](../../scripts/ci/verify-native-release-identity.py)
を接続した。explicit identity を受け取った native-only archive と packaged stage0 は同じ canonical
objectを manifest/fileへ投影し、release smoke は artifact bytes、source commit、manifest/file conflictを
offlineで再検証する。identityが未指定の旧 archive は後方互換の unverified boundaryとして残し、
`NATIVE_ONLY_REQUIRE_REVIEW_EVIDENCE_IDENTITY=1` で strict missing-input failureへ切り替えられる。
provider helperの実取得、current-source native replay、両 target runtimeは次の gateで閉じる。

2026-07-31 の offline input slice では [`prepare-review-evidence-identity.py`](../../scripts/ci/prepare-review-evidence-identity.py)
を追加した。subject digest、source commit、artifact、clock を明示入力とし、trust store と lifecycle
snapshot は両方指定された場合だけ raw bytes の SHA-256 を計算する。出力は verifier と同じ field order
の JSON で、parent directory が存在しない場合は atomic output を開始せず失敗する。これは provider
取得や native runtime の証拠ではなく、caller/provider adapter と release verifier の間の offline
producer boundary を固定する verified partial slice である。`now` は単なる形状チェックではなく、
閏年を含む暦日・時分秒の範囲を Rust の canonical timestamp parser と共有し、preparer と verifier
の両方で不正な日時を fail-closed にする。
さらに verifier は明示された trust-store/lifecycle snapshot を任意に raw bytes から再計算し、
identity digest と一致しない場合を fail-closed にする。provider の取得・認証は外部境界のまま残す。
native-only `scripts/release.sh` には `NATIVE_ONLY_REVIEW_TRUST_STORE` /
`NATIVE_ONLY_REVIEW_LIFECYCLE` の all-or-none wiring を接続し、snapshot 指定時の digest mismatch を
packaging 前に拒否する。

2026-08-01 に verifier の `--manifest` root shape を harden した。配列・null・数値の manifest を
release identity input として渡した場合、Python の `AttributeError` traceback を出さず、return code `1`
と `review_evidence_identity` を示す安定した入力エラーで停止する。`NativeReleaseIdentityTest` の
8 tests（新規 manifest root 3 variantsを含む）で確認した。これは manifest runtime validation の
verified partial sliceであり、native MCP full-tool/provider semantics、current-source target runtime と
packaged bytes parity は未完了のままである。
