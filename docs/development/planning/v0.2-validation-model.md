# L# v0.2 M2-03 — Intent validation model

## 位置づけ

この slice は `lsharp validate` の入力 parser や CLI を先取りせず、M2-02 graph の
事実を assurance report へ写像する純粋な判定 model を固定する。欠落を pass と解釈
せず、contradiction と未完了状態を分離する。

## 判定規則

`IntentGraph::validate()` は次を返す。

- `trace_gaps`: intent に claim が紐付かない、または claim に contract test がない
- `open_questions`: graph に残る `OpenQuestion` node 数
- `independent_reviews`: `Review` evidence のうち `IndependentReview` の数
- `contradicting_observations`: `Contradicted` outcome または `contradicts` edge の
  unique evidence 数
- `status`: `pass` / `fail` / `unknown`

status は次の順に決める。

1. contradiction が一つでもあれば `fail`
2. trace gap、open question、独立 review 0 のいずれかがあれば `unknown`
3. それ以外は `pass`

`unknown` は stakeholder intent の妥当性を宣言しないための状態であり、実装
conformance の `test` 結果とは別軸である。top-level `verified` は生成しない。

JSON projection の実装済み shape は
[`intent-validation.schema.json`](../../schemas/intent-validation.schema.json) に固定する。
`ValidationReport::to_json_string()` はこの shape を返すが、入力 parser/CLI が接続する
までは library projection として扱い、Rust model が正本である。

`ValidationReport::to_text()` も JSON と同じ順序・事実を newline-delimited で出力する。
text/JSON のどちらにも `verified` shortcut はない。

graph manifest の出力 shape は
[`intent-graph.schema.json`](../../schemas/intent-graph.schema.json) に固定する。
`IntentGraph::to_manifest_json_string()` は node、evidence、typed edge、execution、
provenance を登録順のまま deterministic に投影する。manifest の事実と
`ValidationReport` の assurance status は別の wire object として保持し、manifest に
`verified` のような policy shortcut は追加しない。

## 後続境界

- source syntax / project manifest から `IntentGraph` を構築する入力 contract
- `validate` の CLI command wiring と exit code
- source manifest の duplicate node / orphan edge の入力診断 policy
- selfhost/native の report parity

これらはこの判定 model を再利用し、別の RED で固定する。
