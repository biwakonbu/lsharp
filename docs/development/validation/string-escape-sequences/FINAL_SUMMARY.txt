🎯 ANSWER TO YOUR QUESTION
─────────────────────────────────────────────────────────────────────────────

  In L# source code: (print-string "\\n")
  
  Produces: 1 NEWLINE CHARACTER (0x0A)
  NOT:      2 characters: backslash + n (0x5C 0x6E)

🔬 DEFINITIVE PROOF
─────────────────────────────────────────────────────────────────────────────

Source file: crates/lsharp-syntax/src/lexer.rs (lines 158-213)

```rust
b'\\' => {
    let escaped = self.bytes[self.pos];
    match escaped {
        b'n' => value.push('\n'),    // ← 0x0A (actual newline!)
        b't' => value.push('\t'),    // ← 0x09 (tab)
        b'r' => value.push('\r'),    // ← 0x0D (CR)
        b'\\' => value.push('\\'),   // ← 0x5C (single backslash)
        b'"' => value.push('"'),     // ← 0x22 (quote)
        _ => { ... }
    }
}
```

📊 ESCAPE SEQUENCE REFERENCE
─────────────────────────────────────────────────────────────────────────────

  Escape | Produces    | Hex  | Dec | Result
  ─────────────────────────────────────────────
  \n     | Newline     | 0x0A | 10  | (next line)
  \t     | Tab         | 0x09 | 9   | (tab)
  \r     | Carriage Return | 0x0D | 13  | (line start)
  \\     | Backslash   | 0x5C | 92  | \ (literal)
  \"     | Quote       | 0x22 | 34  | " (literal)


🔄 PROCESSING PIPELINE
─────────────────────────────────────────────────────────────────────────────

  "\\n" in Source
       ↓
  [LEXER] Processes escape sequence
       ↓
  Produces: 0x0A (newline byte)
       ↓
  [PARSER] Creates AST
       ↓
  [IR LOWERING] Converts to Vec<u8>
       ↓
  [WASM CODEGEN] Places raw bytes (NO re-escaping)
       ↓
  [RUNTIME] Outputs: newline character
       ↓
  Result: Cursor moves to next line
