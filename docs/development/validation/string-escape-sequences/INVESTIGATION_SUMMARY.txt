ANSWER TO YOUR QUESTION:
────────────────────────────────────────────────────────────────────────────
In L# source code:
  • "\\n" produces a NEWLINE CHARACTER (1 byte: 0x0A)
  • "\\\\" produces a SINGLE BACKSLASH (1 byte: 0x5C)

This is STANDARD programming language behavior - NOT a bug.

DEFINITIVE PROOF:
────────────────────────────────────────────────────────────────────────────
Source file: crates/lsharp-syntax/src/lexer.rs (lines 158-213)

The lexer code shows:
  b'\\' => {
      let escaped = self.bytes[self.pos];
      match escaped {
          b'n' => value.push('\n'),    // ← Produces 0x0A (newline)
          b't' => value.push('\t'),    // ← Produces 0x09 (tab)
          b'r' => value.push('\r'),    // ← Produces 0x0D (CR)
          b'\\' => value.push('\\'),   // ← Produces 0x5C (backslash)
          b'"' => value.push('"'),     // ← Produces 0x22 (quote)
          _ => { ... }
      }
  }
