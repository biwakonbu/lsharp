# ADR: EC-M3 native canonical manifest parity fixture

- Status: Accepted (fixture and harness contract; native runtime pending)
- Date: 2026-07-27
- Scope: EC-M3-01 canonical manifest fixture and native source-file smoke

## Context

The Rust canonical serializer and selfhost adapter already have a Rust-host Wasm parity test,
but the native stage0 lane had no shared source/manifest fixture. Without a fixed byte fixture,
a native smoke could report success without proving that its manifest is the same version 1 wire
value, or that the `unknown` report and exit code are preserved.

## Decision

- Keep one small source fixture and its exact Rust canonical JSON bytes under
  `tests/fixtures/validation/`.
- Make `native-selfhost-dev-source-file-smoke.sh` run the fixture through the native `validate`
  entrypoint with `--format json --emit-manifest`, require `unknown` exit `2`, validate the report
  metrics, and compare the emitted bytes with `cmp`.
- Make the Linux x86 stage0 wrapper copy both fixtures into its VM workdir explicitly.
- Preserve the blocked `cargo`, `rustc`, and host `lsharp` commands so this contract cannot pass by
  silently invoking a Rust or host fallback.

## Evidence

- RED: `test_e2e_ec_m3_canonical_manifest_fixture_matches_rust_oracle` initially failed because
  the fixture did not exist; the native smoke contract test initially failed because the validation
  boundary was absent.
- GREEN: the fixture value/byte oracle and native smoke contract tests pass, the Linux wrapper
  contract test passes, and all three touched shell scripts pass `bash -n`.
- The manifest fixture was generated by the Rust `IntentGraph::to_manifest_json_string()` oracle and
  contains no trailing newline, matching the exact byte comparison performed by the smoke.
- The duplicate-node fixture is rejected by the Rust source adapter and the native smoke contract
  requires exit `1`, a `source validation error:2` diagnostic, and no report or manifest output.
  The Rust oracle additionally checks that the diagnostic identifies `claim:checkout/rejects`; the
  native source currently exposes the stable error code and leaves full span/ID forwarding open.

## Open boundary

This ADR does not claim native runtime completion. A current-source stage0 package with matching
`source_commit` is not present in this worktree, so Mac Apple Silicon and Linux x86_64 actual smoke,
manifest/report differential output, standalone runtime, provenance, and cleanup evidence remain
open in EC-M3-01/04/05. The harness must be run only after such a stage0 artifact is provisioned.
